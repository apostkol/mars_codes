# Paper figure workflows

The code in this directory supports generation of the figures and derived data
used in the paper. Some paper figures are produced here, while others build on
the broader analysis workflows in the [examples directory](../examples/README.md).
These scripts are research workflows with paper-specific filenames and choices,
rather than part of the package's general API.

Most scripts read grids or prepared MAVEN data from the locations configured in
`mars_currents.config` and write figures to the configured plots directory.
Check the input filenames and settings near the top of a script before running
it. From the repository root, use:

```bash
uv run python paper/<script>.py
```

## Main workflows

- `build_pdyn_grids.py` divides observations into low, intermediate, and high
  solar-wind dynamic-pressure populations, builds their grids, and plots the
  solar-wind distributions.
- `pdyn_comparisons.py` compares the pressure-selected grids and reports the
  incident solar-wind power estimates used in the paper.
- `current_profiles.py` and `radial_profiles.ipynb` generate current-density and
  integrated-current profiles.
- `sza_plots.py` produces solar-zenith-angle and altitude panels.
- `azimuth.py`, `various_figures.py`, and `fine_grid.py` contain supporting map
  and higher-resolution figure workflows.
- `move_figures.py` gathers selected outputs into the paper-figure directory.  
  In some cases, further processing/editing is done manually.

The dynamic-pressure workflow reads the authoritative, headerless
`drivers_merge_l2_hires_recent.txt` solar-wind file. Its speed values are already
in km/s. The prepared MAG input must have been generated by
`mars_currents.mse_processing` with `aberration=4`; the paper scripts must not
apply that rotation a second time.

## Figure-movie helper

`pdfs_to_movie.py` converts PDF pages or PNG images into an H.264 MP4 with hard
cuts between frames. For example:

```bash
uv run python paper/pdfs_to_movie.py figure_01.pdf figure_02.pdf \
    --output figures.mp4 --seconds-per-page 0.5
```

The helper requires `ffmpeg` and Poppler's `pdftoppm`. Run it with `--help` for
input ordering, resolution, duration, and overwrite options.
